# Bilonoac Portfolio

A personal portfolio website for **Rythner Bilonoac**, a fourth-year Bachelor of Science in Information Technology (BSIT) student. It presents my background, skills, projects, education, and contact details in one clean, responsive page.

## Features
- White minimalist design with an optional dark mode
- Responsive layout with a mobile hamburger menu
- Smooth scrolling and active-section highlighting
- Project gallery with technology tags
- Contact form with client-side validation

## Built With
HTML5, CSS3, and vanilla JavaScript (no frameworks).

## Featured Projects
- **Bilonoac Portfolio**: this website.
- **ReUseHub**: an academic project built with Flutter, Dart, PHP, and Python.

## Project Structure
```
bilonoac-portfolio/
├── index.html
├── css/style.css
├── js/script.js
└── images/projects/
```

## Run Locally
Open the folder in Visual Studio Code and launch `index.html` with the Live Server extension.

## Note on the Contact Form
The form validates input in the browser but needs a form service (such as Formspree) to actually send email. Set the endpoint in `js/script.js`.
